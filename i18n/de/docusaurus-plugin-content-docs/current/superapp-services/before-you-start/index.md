# Bevor du startest

Bevor du Code anfasst, brauchst du drei Dinge:

1. **Das Vokabular** — KOBIL hat mehrere Produktnamen, die sich überlappen. [Was ist eine Super App?](./what-is-a-superapp) und das [Glossar](./glossary) bringen sie in Reihenfolge.
2. **Einen Test-Tenant** — einen Keycloak-Realm, einen `idp.<tenant>.kobil.com`-Host und einen mIdentity-Test-User. Siehe [Voraussetzungen & Test-Tenant](./prerequisites).
3. **OIDC-Client-Credentials** — mindestens einen User-facing-Client (Authorization Code + PKCE) und einen Server-zu-Server-Client (`client_credentials`). Siehe [Credentials anlegen](./get-credentials).

Plane **10 Minuten** für diesen Abschnitt. Spart dir später Stunden.

| [Glossar](./glossary) | mIdentity vs. mPower vs. mPay vs. mChat vs. SSP — einmalig sauber getrennt |
| [Voraussetzungen & Test-Tenant](./prerequisites) | Die Liste der Dinge, die du bei deinem KOBIL-Kontakt anfragst |
