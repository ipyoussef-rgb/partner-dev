# Before You Start

Before you touch code, you need three things:

1. **The vocabulary** — KOBIL has several product names that overlap. [What is a Super App?](./what-is-a-superapp) and the [Glossary](./glossary) put them in order.
2. **A test tenant** — a Keycloak realm, an `idp.<tenant>.kobil.com` host, and an mIdentity test user. See [Prerequisites & Test Tenant](./prerequisites).
3. **OIDC client credentials** — at least one user-facing client (Authorization Code + PKCE) and one server-to-server client (`client_credentials`). See [Get Your Credentials](./get-credentials).

Plan **10 minutes** to read this section. It saves hours later.
